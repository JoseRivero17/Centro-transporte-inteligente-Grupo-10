# TransitWeb Solutions - Grupo 10

Sitio web institucional para una consultora digital especializada en diseno web responsive, desarrollo de paginas institucionales, optimizacion UX/UI y estrategia digital.

## Paginas incluidas

- `index.html`: presentacion principal, propuesta de valor, metricas, servicios destacados, metodologia y accesos de entrega.
- `servicios.html`: detalle de servicios, entregables y paquetes.
- `integrantes.html`: equipo de trabajo, roles, fotos y portafolios.
- `contacto.html`: formulario visual, datos de contacto y horarios.
- `proyecto-transporte.html`: presentacion del proyecto de transporte.
- `GeoTransporte_Actividad2.pdf`: documentacion del proyecto integrador.
- `diseño.css`: estilos generales y adaptacion responsive.
- `transitweb.js`: comportamiento del enlace al proyecto.

## Accesos principales

- Sitio principal: abrir `index.html`.
- Documentacion: abrir `GeoTransporte_Actividad2.pdf` desde los botones de `index.html`.
- Proyecto Centro de Transporte: usar el boton `Proyecto` del menu o el acceso de la seccion de entrega final.

## Objetivo del sitio

Comunicar de manera profesional la identidad de TransitWeb Solutions, mostrar los servicios de la consultora, presentar al equipo y facilitar el contacto con potenciales clientes.

## Notas de mantenimiento

- Mantener los archivos HTML, CSS, JS, imagenes y PDF en la misma carpeta para conservar las rutas relativas.
- Si se reemplaza el PDF de documentacion, conservar el nombre `GeoTransporte_Actividad2.pdf` o actualizar los enlaces de `index.html`.
- Las fotos del equipo se cargan desde `Thomas.jpg`, `Rodrigo.jpeg` y `Jose.jpeg`.
